# Phase 4.2 Plan 03: Plotly Charts Scientific Styling Summary

**All 5 Plotly-based chart cards now apply scientific styling when StyleManager.isScientificMode() is true - Arial font, black 1.5px axis lines, and hidden interactive chrome**

## Performance

- **Duration:** 9 min

- **Completed:** 2026-01-30T13:02:41Z
- **Tasks:** 3
- **Files modified:** 5

## Accomplishments

- All 5 Plotly-based cards (HistogramCard, ScatterCard, PieChartCard, CorrelationMatrixCard, TimelineCard) support scientific styling
- Scientific mode applies Arial font family to all text elements (axes, labels, legends, annotations)
- Axis lines are black (textColor) with 1.5px width in scientific mode for crisp print output
- All cards re-render when colorScheme changes in global store
- TimelineCard hides zoom controls and viewport indicator in scientific mode

## Decisions Made

1. **ColorScheme watcher pattern:** All cards now watch `globalStore.state.colorScheme` instead of `isDarkMode` for consistent behavior across light/dark/scientific modes
2. **Modebar always hidden:** Even in non-scientific mode, modebar was already hidden - kept consistent
3. **TimelineCard UI chrome hiding:** Zoom controls and viewport indicator hidden in scientific mode as they are interactive UI elements not suitable for publication
