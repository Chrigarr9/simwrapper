# Phase 4.2 Plan 04: Per-Card Export Button Summary

Per-card export button in DashboardCard header enabling PNG/SVG download of individual visualizations.

## What Was Built

### 1. CardConfig Type Extensions (dashboardCard.ts)
Added three new optional fields to the CardConfig interface:

- **exportConfig**: Partial<ExportConfig> - Per-card export settings (format, width, height, scale)
- **exportName**: string - Custom filename override (replaces title-based naming)
- **exportable**: boolean - Explicit control over export button visibility (default based on card type)

### 2. Export Button in DashboardCard Header
Added export dropdown button with the following features:

- **Dropdown Menu**: Click reveals PNG and SVG export options
- **Auto-close**: Dropdown closes when mouse leaves the menu area
- **Conditional Visibility**: Only shown for exportable card types (histogram, scatter, pie, correlation-matrix, timeline, map)
- **Theme-aware Styling**: Uses CSS variables for consistent appearance in light/dark modes

### 3. handleExport Function
Unified export handler that detects and handles both chart types:

```typescript
async function handleExport(format: 'png' | 'svg' = 'png') {
  // 1. Build config from card settings
  const config = { format, filename: props.card.exportName || sanitizeFilename(...) }

  // 2. Try Plotly chart first (.js-plotly-plot selector)
  const plotElement = contentWrapper.value.querySelector('.js-plotly-plot')
  if (plotElement) {
    await downloadPlotlyChart(plotElement, config)
    return
  }

  // 3. Fall back to MapLibre canvas ([data-exportable-map] selector)
  const mapCanvas = contentWrapper.value.querySelector('[data-exportable-map] canvas')
  if (mapCanvas) {
    const dataUrl = mapCanvas.toDataURL('image/png')
    // Trigger download via link click
  }
}
```

## YAML Configuration

Users can now configure export per-card:

```yaml
- type: histogram
  title: Income Distribution
  exportName: figure-1-income       # Custom filename
  exportConfig:
    format: svg                     # Default format
    width: 1600                     # Custom width
    scale: 3                        # Higher resolution

- type: data-table
  title: Raw Data
  exportable: false                 # Hide export button for this card
```
