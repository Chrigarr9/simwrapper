# Phase 04.3 Plan 02: ScatterCard and HistogramCard Color-By Support

Color-by attribute rendering added to ScatterCard and HistogramCard, enabling consistent cross-card coloring driven by dashboard-level colorByAttribute state.

## Overview

This plan extends the color-by feature (established in Plan 01) from MapCard to scatter plots and histograms. Both cards now accept `colorByAttribute` and `colorByOptions` props, automatically detect attribute type (categorical vs numeric) from data values, and render accordingly using StyleManager for consistent colors.

## Implementation Details

### Task 1: ScatterCard Color-By Support

**File:** `src/plugins/interactive-dashboard/components/cards/ScatterCard.vue`

**Changes:**
1. Added `colorByAttribute` and `colorByOptions` props to Props interface
2. Implemented `detectColorByType()` utility function:
   - Returns 'categorical' if non-numeric values exist
   - Returns 'categorical' if numeric but <15 unique values (handles mode IDs)
   - Returns 'numeric' otherwise
3. Modified `buildChartData()` to handle three rendering modes:
   - **Categorical color-by:** Creates separate traces per category value, uses `StyleManager.buildCategoricalColorMap()` for colors, shows legend
   - **Numeric color-by:** Single trace with `marker.color` array, Viridis colorscale, colorbar with attribute label
   - **None (empty string):** Falls back to existing single-color rendering
4. Comparison mode interaction: Baseline trace stays gray (not split by category), filtered data gets color-by colors
5. Event handler preservation: No re-registration of Plotly click/hover handlers (follows existing pattern)
6. Added watcher for `props.colorByAttribute` to trigger re-rendering

**Key Code Patterns:**

```typescript
// Type detection from data
const detectColorByType = (attribute: string): 'categorical' | 'numeric' => {
  const values = props.filteredData.map(row => row[attribute]).filter(v => v !== null && v !== undefined)
  const allNumeric = values.every(v => typeof v === 'number' && !isNaN(v))
  if (!allNumeric) return 'categorical'
  const uniqueValues = new Set(values)
  if (uniqueValues.size < 15) return 'categorical'  // Mode IDs like 1, 2, 3
  return 'numeric'
}

// Categorical: per-category traces
const colorMap = styleManager.buildCategoricalColorMap(colorByValues.map(String))
colorByValues.forEach(categoryValue => {
  traces.push({
    name: toTitleCase(categoryStr),
    marker: { color: colorMap.get(categoryStr) || defaultColor },
    // ... rest of trace config
  })
})

// Numeric: colorscale
traces.push({
  marker: {
    color: colorByValues,
    colorscale: 'Viridis',
    showscale: true,
    colorbar: { title: attributeLabel }
  }
})
```

### Task 2: HistogramCard Color-By Support

**File:** `src/plugins/interactive-dashboard/components/cards/HistogramCard.vue`

**Changes:**
1. Added `colorByAttribute` and `colorByOptions` props to Props interface
2. Implemented same `detectColorByType()` utility function (could be extracted to shared utility in future)
3. Modified `renderChart()` to handle three rendering modes:
   - **Categorical color-by:** Creates stacked bar traces per category, computes histogram bins per category, uses `StyleManager.buildCategoricalColorMap()`, sets `barmode: 'stack'`
   - **Numeric color-by:** Single trace with bars colored by average value of color-by attribute within each bin, Viridis colorscale with colorbar
   - **None:** Falls back to existing single-trace histogram
4. Comparison mode interaction: Baseline bars stay gray, filtered data gets color-by stacked traces or colored bars
5. Click-to-filter behavior: Clicking a colored bar filters by histogram bin (existing behavior), NOT by color-by category - color-by is purely visual
6. Layout adjustments: `barmode: 'stack'` for categorical, extra margin for legend (categorical) or colorbar (numeric)
7. Added watcher for `props.colorByAttribute` to trigger re-rendering

**Key Code Patterns:**

```typescript
// Categorical: stacked bars per category
colorByValues.forEach(categoryValue => {
  const categoryRows = props.filteredData?.filter(
    row => String(row[props.colorByAttribute!]) === categoryStr
  ) || []

  // Compute histogram bins for this category
  const categoryBins = new Map<number, number>()
  displayData.forEach(d => categoryBins.set(d.bin, 0))
  categoryRows.forEach(row => {
    const bin = Math.floor(row[props.column] / binSize) * binSize
    if (categoryBins.has(bin)) categoryBins.set(bin, categoryBins.get(bin)! + 1)
  })

  traces.push({
    type: 'bar',
    name: toTitleCase(categoryStr),
    marker: { color: colorMap.get(categoryStr) || barColor }
  })
})

layout.barmode = 'stack'  // Override for categorical

// Numeric: average-colored bars
const binAverages = displayData.map(d => {
  const binRows = props.filteredData?.filter(row => {
    const bin = Math.floor(row[props.column] / binSize) * binSize
    return bin === d.bin
  }) || []
  const colorValues = binRows.map(row => row[props.colorByAttribute!]).filter(v => v !== null)
  return colorValues.reduce((acc, v) => acc + v, 0) / colorValues.length
})

traces.push({
  marker: {
    color: binAverages,
    colorscale: 'Viridis',
    showscale: true,
    colorbar: { title: attributeLabel }
  }
})
```
