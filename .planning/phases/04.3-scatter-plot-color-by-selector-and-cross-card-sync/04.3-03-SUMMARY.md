### Task 1: PieChartCard Color-By Support and MapCard Migration

**PieChartCard Changes:**

Added `colorByAttribute` prop to interface:
```typescript
colorByAttribute?: string  // Dashboard-level color-by attribute
```

Implemented type detection:
```typescript
const detectColorByType = (attribute: string): 'numeric' | 'categorical' | null => {
  // Same logic as ScatterCard: check if all numeric and >= 15 unique values
  const allNumeric = values.every(v => typeof v === 'number' && !isNaN(v))
  const uniqueCount = new Set(values.map(String)).size
  return (allNumeric && uniqueCount >= 15) ? 'numeric' : 'categorical'
}
```

Created `effectiveColumn` computed:
```typescript
const effectiveColumn = computed(() => {
  if (!props.colorByAttribute) return props.column

  const colorByType = detectColorByType(props.colorByAttribute)

  if (colorByType === 'numeric') {
    debugLog('[PieChartCard] Ignoring numeric color-by attribute — pie charts only support categorical color-by')
    return props.column
  }

  if (colorByType === 'categorical') {
    debugLog('[PieChartCard] Using colorByAttribute for pie grouping:', props.colorByAttribute)
    return props.colorByAttribute
  }

  return props.column
})
```

**Key Behavior:**
- **Categorical color-by:** Pie slices represent categories of the color-by attribute (replaces configured column)
- **Numeric color-by:** Ignored with debug warning (pie charts inherently categorical)
- **None:** Uses configured column (existing behavior)

Updated `pieData` and `baselinePieData` to use `effectiveColumn` instead of `props.column`.

Used `StyleManager.buildCategoricalColorMap` for consistent colors:
```typescript
colorMap.value = styleManager.buildCategoricalColorMap(alphabeticallySorted)
```

This ensures PIE colors match SCATTER trace colors, HISTOGRAM stacked bars, and MAP layers for the same categories.

Added watcher for colorByAttribute changes:

### Task 2: Dashboard-Level ColorLegend with Click-to-Filter

**InteractiveDashboard Changes:**

Added imports:
```typescript

```

Added `dashboardLegendData` computed property:
```typescript
dashboardLegendData(): { title: string; type: 'categorical' | 'numeric'; items?: Array<{ label: string; color: string }>; minValue?: number; maxValue?: number } | null {
  if (!this.colorByAttribute || !this.displayData?.length) return null

  const attribute = this.colorByAttribute
  const values = this.displayData
    .map(row => row[attribute])
    .filter(v => v !== null && v !== undefined)

  if (values.length === 0) return null

  // Auto-detect type (same logic as PieChartCard)
  const allNumeric = values.every(v => typeof v === 'number' && !isNaN(v))
  const uniqueValues = [...new Set(values.map(String))].sort()
  const isCategorical = !allNumeric || uniqueValues.length < 15

  // Get label from colorByOptions
  const attrConfig = this.colorByOptions.find(opt => opt.attribute === attribute)
  const title = attrConfig?.label || toTitleCase(attribute)

  if (isCategorical) {
    const styleManager = StyleManager.getInstance()
    const colorMap = styleManager.buildCategoricalColorMap(uniqueValues)
    return {
      title,
      type: 'categorical',
      items: uniqueValues.map(value => ({
        label: String(value),
        color: colorMap.get(value)!
      }))
    }
  } else {
    const numValues = values as number[]
    return {
      title,
      type: 'numeric',
      minValue: Math.min(...numValues),
      maxValue: Math.max(...numValues)
    }
  }
}
```

Added `isDarkMode` computed for legend styling:

```typescript
isDarkMode(): boolean {

```

Added template in Pug (after tabs, before rows):

```pug
    :max-value="dashboardLegendData.type === 'numeric' ? dashboardLegendData.maxValue : undefined"
```

Implemented click-to-filter handler:
```typescript
handleDashboardLegendClick(label: string) {
  if (!this.filterManager || !this.colorByAttribute) return

  // Toggle category in legend filter set
  if (this.legendFilteredCategories.has(label)) {
    this.legendFilteredCategories.delete(label)
  } else {
    this.legendFilteredCategories.add(label)
  }

  // Update filter
  const filterId = 'dashboard-colorby-legend'
  if (this.legendFilteredCategories.size === 0) {
    // Clear filter if no categories selected
    this.filterManager.clearFilter(filterId)
  } else {
    // Set filter for selected categories
    this.filterManager.setFilter(
      filterId,
      this.colorByAttribute,
      new Set(this.legendFilteredCategories)
    )
  }

  // Increment filter version to trigger reactivity
  this.filterVersion++
  debugLog('[InteractiveDashboard] Legend filter updated:', Array.from(this.legendFilteredCategories))
}
```

Added watcher to clear filter when colorByAttribute changes:
```typescript
colorByAttribute() {
  if (this.filterManager) {
    this.filterManager.clearFilter('dashboard-colorby-legend')
    this.legendFilteredCategories.clear()
    this.filterVersion++
  }
}
```

**Legend Behavior:**

- Disappears when color-by is "None" (empty attribute)
- Clicking a legend item toggles a filter on the color-by attribute column
- Legend colors match the colors used by scatter, histogram, pie, and map cards
