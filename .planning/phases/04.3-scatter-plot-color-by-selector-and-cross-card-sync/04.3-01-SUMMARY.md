# Phase 04.3 Plan 01: ColorBySelector Component and Dashboard-Level State

Central color-by dropdown extracted from MapCard, placed in dashboard header with shared state management.

## Overview

This plan establishes the foundation for cross-card color synchronization by:
1. Extracting MapCard's color-by dropdown into a reusable ColorBySelector component
2. Promoting colorBy configuration from map-level to dashboard-level YAML
3. Managing shared colorByAttribute state in InteractiveDashboard
4. Passing state to all card types via existing prop bindings

## Implementation Details

### ColorBySelector Component

**Location:** `src/plugins/interactive-dashboard/components/controls/ColorBySelector.vue`

**Architecture:**
- Vue 2.7 Composition API with `<script setup lang="ts">`
- Props: `modelValue` (string) and `options` (array of {attribute, label})
- Emits: `update:modelValue` for v-model pattern
- Template: Pug with "None" option first, then v-for over options
- Styling: Extracted from MapCard.vue lines 2608-2640 (control-item, control-label, control-select)

**Key Features:**
- "None" option with empty string value for disabling color-by
- Theme-aware styling using CSS variables (--dashboard-text-primary, --dashboard-bg-primary, etc.)
- Hover and focus states matching MapCard's existing selectors
- Minimum width 100px for consistent dropdown sizing

### InteractiveDashboard Integration

**YAML Parsing:**
```typescript
// Top-level colorBy (new pattern)
colorBy:
  attributes:
    - attribute: main_mode
      label: Transport Mode
    - attribute: distance
      label: Distance

// Falls back to map.colorBy (existing pattern)
map:
  colorBy:
    attributes: [...]
```

**State Initialization:**
Priority order in `mounted()`:
1. `yaml.colorBy.attributes[0].attribute` (first configured attribute)
2. `yaml.map.colorBy.default` (explicit default)
3. `yaml.map.colorBy.attributes[0].attribute` (first map attribute)

**Computed Property:**
```typescript
colorByOptions(): Array<{ attribute: string; label: string; type: 'categorical' | 'numeric' }> {
  return this.yaml.colorBy?.attributes || this.yaml.map?.colorBy?.attributes || []
}
```

**Template Placement:**
ColorBySelector added to `.header-controls` before theme toggle button:
```pug
.header-controls
  color-by-selector(
    v-if="colorByOptions.length > 0"
    :model-value="colorByAttribute"
    :options="colorByOptions"
    @update:model-value="colorByAttribute = $event"
  )
  button.theme-toggle(...)
```

### Prop Flow to Cards

**Already Implemented:**
InteractiveDashboard.vue lines 123 and 126 already pass colorByAttribute and colorByOptions to all card components via the dynamic component binding. No template changes needed.

Cards receiving these props:
- MapCard (already consuming)
- ScatterCard (Plan 02 will implement)
- HistogramCard (potential future use)
- PieChartCard (potential future use)
