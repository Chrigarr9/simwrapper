**Test:**

**Expected:** Clicking a legend entry filters to that category across all visualizations. Second click unfilters.

**Why human:** Interactive click event propagation and visual confirmation of filtering across multiple card types requires runtime browser testing.

#### 3. Comparison Mode with Color-By Active

**Test:**
1. Apply a filter (e.g., via histogram bin selection)
2. Enable comparison mode toggle

4. Verify baseline data appears in gray/transparent across all charts
5. Verify filtered data shows color-by colors

**Expected:** 
- ScatterCard: gray baseline points (rgba(156, 163, 175, 0.3)) behind colored filtered points
- HistogramCard: gray baseline bars behind colored/stacked filtered bars

**Why human:** Visual distinction between baseline and filtered data across multiple chart types with different rendering engines (Plotly) requires human assessment.

#### 4. No Plotly Memory Leaks

**Test:**
1. Open browser console

**Why human:** Memory leak detection requires runtime browser console monitoring over multiple interaction cycles.
